# EchoChat 界面与交互验收

## 已交付行为

- 深蓝外壳与侧栏、浅色阅读画布，深色主题提供独立的阅读、输入、菜单与状态表面。
- 桌面侧栏 248px；平板和折叠状态使用 72px 轨道；手机使用不透明抽屉，并管理遮罩和焦点。
- 消息与输入使用同一套 840px 内容列。输入框始终位于底部，空态建议仅填写草稿。
- 历史按真实日期分组，搜索显示纯文本摘要；标题可交互重命名，删除提供确认。
- 回答方式菜单有清晰说明与选中标记。通知、表单、确认框和操作菜单使用统一样式。
- 思考过程默认折叠，真实流式状态和保存的历史仍可查看。上滚暂停跟随，并提供“回到最新”。
- 回复按完整字素逐步显示，大块内容自适应加速；Markdown 按显示帧更新并缓存未改变的消息。停止、失败、切换对话或隐藏页面时清理显示任务，原始回复与保存状态即时更新。
- 桌面左侧刻度按已加载提问定位，悬停展示纯文本预览，点击跳转并暂停跟随；手机提供定位列表和键盘退出。当前刻度保持可见，加载更早消息后同步增加轮次。
- 手机定位入口并入顶部工具栏；重命名时释放回答方式和定位入口的空间，保留可读的编辑框。多列表格保持列宽并在自身区域横向滚动。
- 当前会话历史加载期间暂停发送；新建对话的迟到响应保留后续导航和草稿。回复生成期间暂不接受历史导入，避免长写事务阻塞流式保存。
- 流式期间复制使用已收到的完整内容；刷新或重开历史直接显示全文。
- 输入、附件、光标和焦点不因空态切换、流式更新或主题变化丢失；语音区分启动、识别、停止与失败。
- 开场保留眼睛跟随、背景纹理显露和短暂轨迹。约 1.4 秒的出口使用同一个品牌元素连续落位、柔和画布展开和错开的工具入场。系统减少动态效果偏好即时生效；设置中可重播。

## 主要文件

- `frontend/src/App.vue`、`assets/base.css`、`assets/main.css`：布局、设计变量和外围组件样式。
- `frontend/src/views/chatMessage.vue`：空态、消息、标题、菜单与阅读滚动。
- `frontend/src/components/chat/`：侧栏、密钥与导入弹窗、输入及附件。
- `frontend/src/composables/useOpening.js`、`components/opening/`：共享品牌转场与背景交互。
- `frontend/src/composables/useSpeechInput.js`、`utils/markdown.js`：真实语音状态与安全代码语言展示。
- `frontend/src/composables/useStreamingDisplay.js`、`useConversationNavigation.js`、`components/chat/ConversationNavigator.vue`：逐步呈现与对话回溯定位。
- `tests/browser_*.py`：隔离浏览器回归。Windows 测试进程使用工作区临时目录，供 SQLite 级联删除创建临时日志。

## 验证

- 前端：`npm run lint`、`npm test`（23 项）、`npm run build` 通过。历史加载与新建导航竞态均有回归覆盖。
- 后端：在 `backend/` 执行 `uv run pytest -q`，54 项通过。长历史的单对话删除、清空、附件级联和其他对话保留均已覆盖；当前服务的 100 条合成消息对话删除返回 204。生成期间拒绝导入，完成或取消后的片段保存和重新导入均已验证。
- `browser_layout.py`：1440×900、1920×1080、1024×768、390×844、320×700、1440×560 全部通过。
- 320px 和 390px 手机场景覆盖纯中文四列表格的可读列宽、局部滚动、标题编辑宽度及 44px 控件；定位入口位于现有顶部栏，不占独立阅读行。Enter 开启和保存重命名、Escape 取消及输入法确认不误保存均已验证。
- `browser_smoke.py`：密钥、语音启动与权限失败、IME、上传、草稿、流式归属、停止、上滚、错误、导入、思考历史、复制与重命名焦点通过。
- `browser_streaming.py`：8 项通过，覆盖单大块、小片段、短片段后长代码、停止、部分错误、切换、刷新、减少动态效果及定位。模拟模型的一个大块产生 21 个中间前缀；两种 160 行代码路径均能在显示未完成时复制完整已接收代码。
- 对话定位：悬停关联预览、真实测量后的落位与高亮、接收新片段时保持回溯位置、回到最新、手机键盘进入和退出以及关闭动画后的焦点恢复通过。定位操作不新增模型请求。
- 100 轮定位轨道：当前刻度保持在轨道可视区；回到首轮后轨道同步回到顶部。轨道调整造成的主对话额外滚动位移为 0。
- `browser_opening.py`：首访、键盘进入、连续落位、背景与轨迹、重播保留、响应式、缩放中断及减少动态效果通过。
- 浏览器脚本按 `backend/pyproject.toml` 的 Ruff 配置检查通过；最终差异检查无空白错误。

截图保存在 `test-results/ui-empty-light.png`、`ui-long-light.png`、`ui-dark.png`、`ui-mobile.png`，以及深浅回答菜单与上传反馈截图。定位效果见 `streaming-navigation-desktop.png`、`streaming-navigation-mobile.png`，逐帧验证数据见 `streaming-*.json`。

## 验证边界

业务浏览器回归使用隔离数据库和模拟模型，没有新增真实 DeepSeek 请求。逐步显示改善已到达内容的呈现；模型尚未返回内容时仍需等待，测试数据不代表真实 DeepSeek 的网络延迟。真实手机软键盘与实际语音授权流程尚未进行设备验证。构建仍提示现有单包体积较大。
