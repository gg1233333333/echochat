# 运行记录、工具权限和模型接口

本阶段只实现三项能力，保留个人本机、单进程和单个活动运行的使用范围。沿用原有聊天界面、LangGraph 编排、流式取消、单次请求超时及网页读取保护。

## 运行记录

`runs` 为运行生命周期的持久化来源，`messages` 保留用户可见正文、思考和工具快照。创建回复与排队运行在一个事务中提交；每个运行有独立于请求 ID 和消息 ID 的稳定 run_id。正文快照、工具快照和运行计数在保存边界更新，终态与消息投影在同一事务落库。`run_events` 使用单调序号保存接受、开始、模型/工具开始与结束、运行终态；事件只存步骤元信息，不存 API Key 或重复的完整提示词。

状态允许 queued → running/cancelled/failed/interrupted，running → completed/cancelled/failed/interrupted。终态不能回到运行中。启动迁移后，遗留 queued/running 明确标记 interrupted，保留已有输出和工具结果，不自动请求模型或重放工具。checkpoint 指向已保存的消息/工具快照和计数，不是可自动续跑的 LangGraph checkpointer。历史记录迁入时标注 legacy，未知调用数保持 null。

接口：GET /api/runs/{run_id}；GET /api/runs/{run_id}/events?after_seq=0&limit=100；POST /api/runs/{run_id}/cancel。原请求 ID 取消接口继续兼容。消息返回 run_id，现有消息下的“运行记录”按需打开，不增加全局执行面板。运行记录和事件随消息/对话级联删除。

## 工具权限与幂等

权限入口默认收起，逐工具选择保存在浏览器。发送时携带工具名称数组，后端验证名称并固定该次权限快照；模型只收到允许工具的 schema，ToolRuntime 仍独立拒绝所有越权执行。关闭全部工具时不向模型发送工具定义。工具/网页/附件内容仅作数据，不能修改运行权限；不承诺从语义上消灭提示词注入。

已保留消息的重复请求 ID 返回已有运行与产物。文件工具操作键由消息、模型轮次和工具调用 ID 派生，SQLite 唯一索引配合冲突不插入保证相同操作重复执行返回同一文件；同一键参数改变明确失败，不覆盖文件。不同的明确工具调用仍可生成不同产物。没有自动重试或外部副作用工具，因此不宣称实现通用 exactly-once 执行。

## 模型接口

ChatCompletionsProvider 承担地址、模型名、协议参数、HTTP/SSE 和上游错误分类；AgentExecution 只处理模型片段、工具协议及图状态。支持 DeepSeek 扩展和 OpenAI Chat Completions 文本/函数工具兼容形状。服务配置不含密钥，运行保存非敏感 provider 快照；运行中不能更换配置。更换地址或协议时清除原密钥，避免悄然发送到另一个服务。

公网服务使用 HTTPS；除明确本机地址外拒绝非公网解析，连接固定到验证的地址并保留 Host/SNI 和 TLS 证书校验。内置固定 DeepSeek HTTPS 地址保持标准 DNS/TLS；禁止所有 provider 重定向，HTTP 客户端不读取环境代理。密钥只附在对已保存服务的后端请求中，不返回配置接口、运行记录或原始上游错误。

GET /models 连接测试不生成 token，仅证明该端点连通。真实模型、工具、思考和计费兼容性需要用户自行提供对应服务密钥后另行明确验证；自动回归只用假密钥和 MockTransport。

## 验收

- 稳定 run_id、事件序号和游标分页；重复请求不增加模型调用；刷新查询与原回复关联。
- 取消终态、失败分类、迁移保留历史、进程重启中断；不自动恢复；终态逆转被拒绝。
- 可见与执行 allowlist 一致；模拟恶意工具内容诱导越权写文件时，后端拒绝且没有产物。
- 同一文件操作键幂等及参数冲突；删除/重新生成继续级联清理。
- Provider 非敏感配置持久化、目标变更清除密钥、OpenAI 模式不发送 DeepSeek 专有参数、GET /models 不调用生成端点、私网解析与重定向不转发凭据。
- 浏览器 1440、390、320 像素下权限默认收起、选择刷新保留、运行记录可重新打开、模型接口设置和无生成连接测试；保留现有冒烟、布局、开场和流式回归。

本阶段不包含自定义助手、多 Agent、整体执行面板改版、应用内备份导出、多用户、集群或部署。交付包含经检查的 GitHub 代码和源码压缩包；源码包不含运行数据与已安装依赖，启动方式见 START_HERE.md，分发权利待确认项见 THIRD_PARTY_NOTICES.md。

密钥设置在打开弹窗时显示并固定目标地址/协议；保存时后端在同一锁下核对目标，过期弹窗或不带目标的自定义服务请求返回 409，需重新打开核对。旧版不带目标的密钥请求仅兼容默认 DeepSeek 地址及协议。运行接受时原子固定目标和密钥；自定义固定 IP 的连接每次关闭，避免同 IP 不同域名复用 TLS 身份。

任务执行不设模型轮次、工具总次数或总时长上限。LangGraph 每次执行一个有限的模型/工具周期，外层循环保留上下文和累计计数；计数用于记录，不作为总预算。每次模型请求有 120 秒硬超时，每次工具有 20 秒超时，输出累计最多 500000 字符，单次响应工具索引最多 48 个。取消、工具权限和重复同参失败停止仍生效，停止/错误保留已有内容、工具结果和产物，状态准确标记。
