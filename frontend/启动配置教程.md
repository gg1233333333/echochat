# 项目启动配置教程

请按[仓库启动说明](../README.md)先启动 FastAPI，再启动 Vue 前端。

- DeepSeek API Key 只保存在 `backend/.env` 的 `DEEPSEEK_API_KEY`。
- 前端不配置任何 API Key；旧的前端密钥变量应删除。
- 默认前端开发代理目标为 `http://127.0.0.1:8000`。
- 生产环境鉴权、TLS 与限流见[后端部署说明](../backend/README.md)。

前端检查命令：

```bash
npm ci
npm test
npm run lint:check
npm run build
npm run check:bundle
```
