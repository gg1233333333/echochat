# 项目启动配置教程

## 项目介绍

这是一个基于 Vue 3、Vite 和 DeepSeek Chat API 的多角色 AI 对话应用。

## 前置准备

### 1. 安装 Node.js

- 推荐使用 Node.js 20+ 版本
- 下载地址：<https://nodejs.org/>
- 安装完成后，在终端输入以下命令检查是否安装成功：

```bash
node -v
npm -v
```

## 启动步骤

### 第一步：安装项目依赖

在项目根目录下打开终端，执行以下命令：

```bash
npm install
```

这个命令会自动安装 package.json 中列出的所有依赖包。

### 第二步：配置 API Key

1. 在项目根目录下，复制 `.env.example` 文件并重命名为 `.env`：

Windows PowerShell:

```powershell
Copy-Item .env.example .env
```

或者手动重命名也可以。

1. 打开 `.env` 文件，将 `VITE_DEEPSEEK_API_KEY` 的值替换为你自己的 DeepSeek API Key：

```env
VITE_DEEPSEEK_API_KEY=sk-你的真实API密钥
```

\*\*如何获取 DeepSeek API Key：

1. 访问 <https://platform.deepseek.com/>
2. 注册/登录账号
3. 进入 API Keys 页面
4. 创建新的 API Key 并复制

### 第三步：启动开发服务器

在项目根目录下执行：

```bash
npm run dev
```

启动成功后，终端会显示一个本地地址

## 其他命令

- `npm run build` - 构建生产版本
- `npm run preview` - 预览构建结果

## 常见问题

**Q: npm install 很慢怎么办？**
A: 可以尝试使用淘宝镜像：

```bash
npm config set registry https://registry.npmmirror.com
```

**Q: 启动后显示 API 报错？**
A: 请检查 .env 文件中的 API Key 是否正确配置，以及 API Key 是否还有余额。

**Q: 支持哪些浏览器？**
A: 推荐使用 Chrome、Edge 等现代浏览器。
